# 快速測試 - 立即觸發磁力計警告

## 🎯 手動測試 (立即見效)

在 SITL 視窗 (tmux `Ctrl+b 1`) 執行:

```bash
# 測試 1: 強偏移 (應該立即觸發 Compass Unhealthy)
param set SIM_MAG1_OFS_X 2000
param set SIM_MAG1_OFS_Y 1600
param set SIM_MAG1_OFS_Z 2400

# 等待 2-3 秒,觀察 QGC 是否出現紅色警告
```

**預期結果**:
- QGC 顯示 "Compass Unhealthy" (紅色)
- EKF 可能切換到 GPS-only 模式
- 可能無法解鎖或自動切換到 STABILIZE

---

## 🚀 使用修改後的腳本

```bash
python3 production_compass_interference.py
```

**改進內容**:
1. ✅ 改用 `SIM_MAG1_OFS_*` (立即生效,不需電流)
2. ✅ 增強干擾強度: 0.75x → 3.5x (原 2.0x)
3. ✅ 基礎偏移: 2000 mGauss
4. ✅ 峰值偏移: ~5000 mGauss (3.5x 時)

**時間軸**:
- 0-15秒: 正常 (偏移 = 0)
- 15-45秒: 漸增 (偏移 0 → 5000 mGauss)
- 45-55秒: 嚴重 (偏移 = 5000 mGauss) 🔴
- 55-70秒: 恢復 (偏移 5000 → 0)

## 🔍 驗證方法

### 方法 1: 查看 QGC 訊息
- 正常: 綠色,無警告
- 輕度: 黃色 "Compass variance"
- 嚴重: 紅色 "Compass Unhealthy"

### 方法 2: 檢查參數值
```bash
# 在腳本運行時,另開終端執行
python3 check_mag_params.py
```

### 方法 3: 查看 SITL 日誌
```bash
# 切換到 SITL 視窗
tmux attach -t ardu_sim
# 按 Ctrl+b 1 (SITL 視窗)
# 觀察是否有 EKF 警告訊息
```

## ⚠️ 如果還是沒有警告

### 可能原因 1: 閾值太高
修改腳本增加基礎偏移:
```python
# 第 50 行
'base_offset': 3000,  # 改為 3000 (原 2000)
```

### 可能原因 2: EKF 設定太寬鬆
檢查 EKF 參數:
```bash
param show EKF*MAG*
```

### 可能原因 3: 磁力計校準問題
重新校準:
```bash
# 在 SITL 視窗
magcal
```
