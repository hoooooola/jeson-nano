# 磁力計干擾訓練方案 (Compass Interference Training)

## 🎯 訓練目標

模擬無人機磁力計受到干擾時的緊急處置程序,訓練飛行者在磁力計不健康 (Compass Unhealthy) 情況下的應對能力。

## 📊 磁力計干擾類型與參數

### 1. 馬達電流干擾 (Motor Current Interference)

**參數**: `SIM_MAG_MOT`  
**單位**: mGauss/A (毫高斯/安培)  
**說明**: 模擬馬達電流對磁力計的干擾

**地球磁場強度參考**:
- 台灣地區磁場總強度: ~45,000 mGauss (45 µT)
- 健康範圍: 通常為 0.5~2.0 倍地球磁場強度
- 即: 22,500~90,000 mGauss

**干擾強度設定**:
```bash
# 輕度干擾 (模擬輕微馬達干擾)
param set SIM_MAG_MOT_X 500
param set SIM_MAG_MOT_Y 500
param set SIM_MAG_MOT_Z 500

# 中度干擾 (開始影響航向精度)
param set SIM_MAG_MOT_X 1500
param set SIM_MAG_MOT_Y 1500
param set SIM_MAG_MOT_Z 1500

# 重度干擾 (觸發 Compass Unhealthy 警告)
param set SIM_MAG_MOT_X 3000
param set SIM_MAG_MOT_Y 3000
param set SIM_MAG_MOT_Z 3000
```

**效果**: 油門越高,干擾越大 (模擬真實馬達磁場干擾)

---

### 2. 磁場異常 (Magnetic Anomaly)

**參數**: `SIM_MAG_ALY`, `SIM_MAG_ALY_HGT`  
**單位**: mGauss (毫高斯), m (公尺)  
**說明**: 模擬地面局部磁場異常 (如鋼筋建築、金屬物體)

**設定範例**:
```bash
# 模擬地面有強磁性物體 (如鋼筋、變壓器)
param set SIM_MAG_ALY_X 10000   # 北向異常 10,000 mGauss
param set SIM_MAG_ALY_Y 5000    # 東向異常 5,000 mGauss
param set SIM_MAG_ALY_Z -8000   # 下向異常 -8,000 mGauss
param set SIM_MAG_ALY_HGT 5     # 5公尺高度時衰減到 1/8

# 極端異常 (模擬停車場、鋼構建築)
param set SIM_MAG_ALY_X 25000
param set SIM_MAG_ALY_Y 25000
param set SIM_MAG_ALY_Z -20000
param set SIM_MAG_ALY_HGT 3
```

**效果**: 越接近地面,干擾越強;高度上升後干擾減弱

---

### 3. 磁力計偏移 (Compass Offset)

**參數**: `SIM_MAG1_OFS`  
**單位**: mGauss  
**說明**: 模擬磁力計校準不良或硬鐵干擾

**設定範例**:
```bash
# 模擬校準偏移
param set SIM_MAG1_OFS_X 5000
param set SIM_MAG1_OFS_Y -3000
param set SIM_MAG1_OFS_Z 4000

# 嚴重偏移 (會觸發 PreArm: Compass offsets too high)
param set SIM_MAG1_OFS_X 15000
param set SIM_MAG1_OFS_Y 15000
param set SIM_MAG1_OFS_Z 15000
```

---

### 4. 磁力計縮放錯誤 (Scaling Error)

**參數**: `SIM_MAG1_SCALING`  
**單位**: 無單位 (倍數)  
**說明**: 模擬磁力計讀數縮放錯誤

**設定範例**:
```bash
# 正常
param set SIM_MAG1_SCALING 1.0

# 讀數偏小 (0.5倍 = 磁場強度減半)
param set SIM_MAG1_SCALING 0.5

# 讀數偏大 (2.0倍 = 磁場強度加倍)
param set SIM_MAG1_SCALING 2.0

# 極端錯誤 (會觸發 Compass Unhealthy)
param set SIM_MAG1_SCALING 0.3   # 或 3.0
```

---

### 5. 完全故障 (Complete Failure)

**參數**: `SIM_MAG1_FAIL`  
**值**: 0 (正常) / 1 (故障)  
**說明**: 模擬磁力計完全失效

**設定範例**:
```bash
# 觸發 MAG1 完全故障
param set SIM_MAG1_FAIL 1

# 恢復正常
param set SIM_MAG1_FAIL 0
```

## 🎓 訓練課程設計

### 課程 1: 輕度干擾識別

**目標**: 學習識別磁力計輕微干擾的徵兆

**設定**:
```bash
param set SIM_MAG_MOT_X 800
param set SIM_MAG_MOT_Y 800
param set SIM_MAG_MOT_Z 800
```

**訓練步驟**:
1. 起飛到 5 公尺
2. 觀察 QGC 中的 Compass 狀態
3. 執行慢速圓周飛行
4. 觀察航向 (Heading) 是否有輕微漂移

**預期現象**: 航向略有不穩,但仍可控制

---

### 課程 2: 中度干擾應對

**目標**: 在磁力計受干擾時切換到 GPS 導航模式

**設定**:
```bash
param set SIM_MAG_MOT_X 2000
param set SIM_MAG_MOT_Y 2000
param set SIM_MAG_MOT_Z 2000
param set SIM_MAG1_SCALING 1.5
```

**訓練步驟**:
1. 起飛並切換到 LOITER 模式
2. 觀察 QGC 顯示 "Compass variance" 警告
3. 練習使用 GPS 位置保持 (而非依賴航向)
4. 嘗試手動控制返航

**預期現象**: 
- QGC 顯示黃色警告
- 航向不穩定,但 GPS 定位正常
- 自動航線可能偏離

---

### 課程 3: 重度干擾緊急處置

**目標**: 磁力計不健康時的緊急降落程序

**設定**:
```bash
param set SIM_MAG_MOT_X 4000
param set SIM_MAG_MOT_Y 4000
param set SIM_MAG_MOT_Z 4000
param set SIM_MAG1_SCALING 0.4
```

**訓練步驟**:
1. 起飛到 10 公尺
2. 等待 "Compass Unhealthy" 紅色警告
3. **立即切換到 STABILIZE 或 ALT_HOLD 模式**
4. 手動控制降落 (不依賴航向)

**預期現象**:
- QGC 顯示紅色 "Compass Unhealthy"
- 可能觸發 EKF 錯誤
- 自動模式 (LOITER/AUTO) 可能失效

**關鍵處置**:
- ✅ 切換到不依賴磁力計的模式 (STABILIZE, ALT_HOLD)
- ✅ 使用目視手動控制
- ❌ 不要使用 RTL (Return To Launch) - 可能因航向錯誤而飛錯方向

---

### 課程 4: 磁場異常區域飛行

**目標**: 模擬在鋼構建築附近飛行

**設定**:
```bash
param set SIM_MAG_ALY_X 15000
param set SIM_MAG_ALY_Y 10000
param set SIM_MAG_ALY_Z -12000
param set SIM_MAG_ALY_HGT 4
```

**訓練步驟**:
1. 在地面觀察磁力計讀數 (應該異常)
2. 起飛並爬升到 10 公尺
3. 觀察磁力計讀數隨高度恢復正常
4. 練習在不同高度的控制差異

**預期現象**:
- 地面: 磁力計嚴重偏差
- 5 公尺: 干擾減弱
- 10 公尺: 基本恢復正常

---

### 課程 5: 完全故障模擬

**目標**: 無磁力計情況下的飛行

**設定**:
```bash
param set SIM_MAG1_FAIL 1
```

**訓練步驟**:
1. 嘗試解鎖 (可能需要強制解鎖)
2. 僅使用 STABILIZE 模式起飛
3. 練習無航向參考的手動控制
4. 安全降落

**預期現象**:
- PreArm 檢查失敗
- 所有依賴航向的模式不可用
- 僅能使用 STABILIZE 模式

---

## 🔧 快速指令參考

### 查看當前磁力計狀態
```bash
# 在 MAVProxy 中
status

# 查看磁力計參數
param show SIM_MAG*
param show COMPASS*
```

### 重置所有干擾
```bash
param set SIM_MAG_MOT_X 0
param set SIM_MAG_MOT_Y 0
param set SIM_MAG_MOT_Z 0
param set SIM_MAG1_SCALING 1.0
param set SIM_MAG1_OFS_X 0
param set SIM_MAG1_OFS_Y 0
param set SIM_MAG1_OFS_Z 0
param set SIM_MAG_ALY_X 0
param set SIM_MAG_ALY_Y 0
param set SIM_MAG_ALY_Z 0
param set SIM_MAG1_FAIL 0
```

### 保存參數
```bash
param save
```

## 📈 干擾強度對照表

| 干擾等級 | SIM_MAG_MOT | SIM_MAG1_SCALING | 磁場總強度 (相對地球磁場) | 狀態 |
|---------|-------------|------------------|------------------------|------|
| 正常 | 0 | 1.0 | 1.0x (45,000 mGauss) | ✅ 健康 |
| 輕度 | 500-1000 | 0.9-1.1 | 0.9-1.1x | ⚠️ 輕微警告 |
| 中度 | 1500-2500 | 0.7-1.4 | 0.7-1.4x | ⚠️ Variance 警告 |
| 重度 | 3000-5000 | 0.5-2.0 | 0.5-2.0x | 🔴 Unhealthy |
| 極端 | >5000 | <0.3 或 >3.0 | <0.3x 或 >3.0x | 🔴 EKF 失效 |

## ⚠️ 安全注意事項

1. **僅在模擬環境中練習** - 切勿在真機上設定這些參數
2. **熟悉緊急模式切換** - 確保能快速切換到 STABILIZE
3. **保持低高度訓練** - 建議 5-10 公尺高度
4. **準備強制解鎖** - 嚴重干擾可能需要 `arm throttle force`
5. **記錄參數** - 訓練前記錄原始參數,訓練後恢復

---

## 🎯 訓練成果檢核

完成訓練後,學員應能:
- ✅ 識別磁力計干擾的早期徵兆
- ✅ 理解不同干擾類型的差異
- ✅ 快速切換到不依賴磁力計的飛行模式
- ✅ 在無航向參考下安全降落
- ✅ 判斷何時應中止任務並緊急降落

---

**建議訓練順序**: 課程 1 → 課程 2 → 課程 4 → 課程 3 → 課程 5

**預計訓練時間**: 每課程 15-20 分鐘,總計 1.5-2 小時
