## 🔍 問題分析

### 為什麼 QGC 會斷線?

根據您的專業分析,主要有兩個原因:

#### 1. Port 搶佔 (Port Conflict)
```
SITL → UDP 14550 → QGC ✅
       ↓
Python 腳本 (也連 14550) ❌ 搶走封包!
```

**解決方案**: 使用不同的端口
- QGC: 14550
- Python 腳本: 14551 (MAVROS/API 專用)

#### 2. 頻寬阻塞 (Link Flooding)
```python
# 問題代碼 (每秒發送 60 次參數!)
for i in range(20):
    set_param(...)  # 3 個參數
    set_param(...)
    set_param(...)
    time.sleep(1)   # 每秒 3 個參數 × 20 步 = 60 次/秒
```

**後果**:
- MAVLink 緩衝區塞爆
- Heartbeat 超時
- QGC 判定為斷線

**解決方案**:
```python
# 安全代碼 (每秒 2 次)
set_param(...)
set_param(...)
set_param(...)
time.sleep(0.5)  # 每 0.5 秒更新一次
```

## 📝 關鍵優化點總結

### 1. 避開 QGC Port ✅
```python
# 錯誤
CONNECTION_STRING = 'udp:127.0.0.1:14550'  # QGC 的端口!

# 正確
CONNECTION_STRING = 'udp:127.0.0.1:14551'  # API 專用端口
```

### 2. 控制更新頻率 ✅
```python
# 錯誤 - 太快!
time.sleep(0.1)  # 10 Hz

# 正確 - 安全頻率
time.sleep(0.5)  # 2 Hz
```

### 3. 自動清理 ✅
```python
try:
    # 模擬邏輯
    ...
except KeyboardInterrupt:
    print("用戶中斷")
finally:
    # 關鍵! 自動重置參數
    for _ in range(3):
        set_param(master, PARAM_MAG_MOT_X, 0.0)
        time.sleep(0.2)
```

### 4. 錯誤處理 ✅
```python
def set_param_safe(master, param_name, value, retry=3):
    for attempt in range(retry):
        try:
            master.mav.param_set_send(...)
            return True
        except Exception as e:
            if attempt == retry - 1:
                print(f"設定失敗: {e}")
            time.sleep(0.05)
    return False
```
