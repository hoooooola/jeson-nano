# 磁力計參數問題診斷

## 🔍 問題發現

### 錯誤的參數名稱

❌ **我們一直在用錯誤的參數**:
```python
PARAM_MAG_MOT_X = b'SIM_MAG_MOT_X'  # 不存在!
PARAM_MAG_MOT_Y = b'SIM_MAG_MOT_Y'  # 不存在!
PARAM_MAG_MOT_Z = b'SIM_MAG_MOT_Z'  # 不存在!
```

✅ **正確的參數名稱**:
```python
# SIM_MAG_MOT 是一個 Vector3 參數
# 需要用以下方式設定:
SIM_MAG_MOT_X  # X 軸分量
SIM_MAG_MOT_Y  # Y 軸分量  
SIM_MAG_MOT_Z  # Z 軸分量
```

### 源碼證據

從 `SITL.cpp` 第 760 行:
```cpp
// @Param: MAG_MOT
// @DisplayName: Motor magnetic interference
// @Description: Simulates distortion of magnetometer readings caused by motor current
// @Units: mGauss/A
// @Vector3Parameter: 1
AP_GROUPINFO("MAG_MOT", 2, SIM, mag_mot, 0),
```

**關鍵**: `@Vector3Parameter: 1` 表示這是一個向量參數!

### 如何使用 Vector3 參數

在 MAVProxy 中,Vector3 參數的設定方式:

```bash
# 方法 1: 分別設定各軸 (推薦)
param set SIM_MAG_MOT_X 5000
param set SIM_MAG_MOT_Y 4000
param set SIM_MAG_MOT_Z 6000

# 方法 2: 查看當前值
param show SIM_MAG_MOT*
```

## 🎯 正確的測試方法

### 測試 1: 使用偏移參數 (立即生效)

```bash
# 這個參數會直接影響磁力計讀數
param set SIM_MAG1_OFS_X 500
param set SIM_MAG1_OFS_Y 500
param set SIM_MAG1_OFS_Z 500
```

**單位**: mGauss (毫高斯)  
**效果**: 直接加到磁力計讀數上

### 測試 2: 使用磁場異常 (地面干擾)

```bash
# 模擬地面磁場異常
param set SIM_MAG_ALY_X 10000
param set SIM_MAG_ALY_Y 10000
param set SIM_MAG_ALY_Z -15000
param set SIM_MAG_ALY_HGT 5
```

**效果**: 越接近地面干擾越強

### 測試 3: 縮放因子 (最直接)

```bash
# 改變磁場強度
param set SIM_MAG1_SCALING 0.3   # 磁場變弱
# 或
param set SIM_MAG1_SCALING 3.0   # 磁場變強
```

**效果**: 直接改變磁場總強度

### 測試 4: 完全故障

```bash
param set SIM_MAG1_FAIL 1
```

**效果**: 磁力計完全失效

## 🔧 為什麼 SIM_MAG_MOT 無效?

### 原因分析

從源碼 `SIM_Aircraft.cpp` 第 245 行:
```cpp
mag_bf += sitl->mag_mot.get() * battery_current;
```

**關鍵發現**: `SIM_MAG_MOT` 需要與 **電池電流** 耦合!

也就是說:
1. `SIM_MAG_MOT` 本身只是一個係數
2. 實際干擾 = `SIM_MAG_MOT` × `battery_current`
3. 如果電池電流很小,干擾就很小

### 驗證方法

```bash
# 1. 檢查電池電流
# 在 MAVProxy 中
status

# 2. 增加油門 (增加電流)
rc 3 1700  # 油門拉高

# 3. 然後設定 SIM_MAG_MOT
param set SIM_MAG_MOT_X 5000
```

## ✅ 推薦的測試順序

### 立即見效的方法 (推薦)

```bash
# 1. 使用偏移 (最直接)
param set SIM_MAG1_OFS_X 1000
param set SIM_MAG1_OFS_Y 800
param set SIM_MAG1_OFS_Z 1200

# 2. 或使用縮放
param set SIM_MAG1_SCALING 0.3

# 3. 觀察 QGC 是否出現警告
```

### 需要油門配合的方法

```bash
# 1. 先拉高油門
rc 3 1800

# 2. 設定馬達干擾
param set SIM_MAG_MOT_X 5000
param set SIM_MAG_MOT_Y 4000
param set SIM_MAG_MOT_Z 6000

# 3. 觀察效果
```

## 📊 參數對照表

| 參數 | 單位 | 是否需要電流 | 立即生效 | 推薦值 |
|------|------|------------|---------|--------|
| `SIM_MAG1_OFS_*` | mGauss | ❌ 否 | ✅ 是 | 500-2000 |
| `SIM_MAG_MOT_*` | mGauss/A | ✅ 是 | ⚠️ 需油門 | 3000-5000 |
| `SIM_MAG_ALY_*` | mGauss | ❌ 否 | ✅ 是 | 10000-20000 |
| `SIM_MAG1_SCALING` | 無 | ❌ 否 | ✅ 是 | 0.3-3.0 |
| `SIM_MAG1_FAIL` | 0/1 | ❌ 否 | ✅ 是 | 1 |

## 🎯 結論

**問題根源**: 我們一直在用 `SIM_MAG_MOT`,但這個參數需要與電池電流耦合才有效。

**解決方案**: 改用 `SIM_MAG1_OFS_*` 或 `SIM_MAG1_SCALING`,這些參數立即生效且不依賴電流。

**下一步**: 修改 Python 腳本使用正確的參數。
