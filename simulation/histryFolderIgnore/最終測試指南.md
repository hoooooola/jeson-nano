## 🐛 故障排除

### 問題 1: 連接失敗
```
❌ 連線失敗: [Errno 111] Connection refused
```

**解決**:
1. 確認 SITL 已啟動: `tmux ls | grep ardu_sim`
2. 檢查端口: `netstat -tuln | grep 5762`
3. 等待 10 秒後重試

### 問題 2: 無 Compass 警告

**可能原因**:
- 干擾強度不足
- EKF 參數太寬鬆

**解決**:
手動測試極限值:
```bash
# 在 SITL 視窗
param set SIM_MAG1_OFS_X 10000
param set SIM_MAG1_OFS_Y 10000
param set SIM_MAG1_OFS_Z 10000
```

這個值**一定**會觸發警告!

### 問題 3: QGC 斷線

**解決**:
- 確認腳本使用 TCP 5762 (不是 14550)
- 檢查 `production_compass_interference.py` 第 23 行
