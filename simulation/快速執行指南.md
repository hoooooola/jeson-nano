# 快速執行指南 - 磁力計干擾模擬

## ✅ 環境已就緒

- **pymavlink**: 已安裝 (v2.4.49)
- **執行位置**: Host 主機 (當前終端 ProcessId: 11677)
- **腳本位置**: `/media/user/windowsData1/gitClone/GitProject/jesonEcosys/simulation/`

## 🚀 快速開始 (3 步驟)

### 步驟 1: 啟動 SITL (如果尚未啟動)

```bash
cd /media/user/windowsData1/gitClone/GitProject/jesonEcosys/simulation
./launch_all.sh
```

選擇: `1` (ArduCopter) → `1` (Quad X)

### 步驟 2: 起飛

在 tmux SITL 視窗 (`Ctrl+b 1`) 中執行:

```bash
mode GUIDED
arm throttle
takeoff 10
```

等待無人機穩定在 10 公尺。

### 步驟 3: 執行干擾模擬

**在當前終端 (Host 主機) 執行**:

```bash
python3 simulate_compass_interference.py
```

按 Enter 開始模擬。

## 📊 預期結果

模擬會經過 4 個階段:

1. **Phase 1** (0-10秒): 正常飛行,磁場強度 0.75x
2. **Phase 2** (10-30秒): 干擾漸增,0.75x → 2.0x
3. **Phase 3** (30-35秒): 嚴重干擾,磁場強度 2.0x
   - ⚠️ 預期: "Compass Unhealthy" 警告
   - 🔴 建議: 切換到 STABILIZE 模式
4. **Phase 4** (35-45秒): 恢復正常,2.0x → 1.0x

## 🎮 應對練習

當看到 "Compass Unhealthy" 時:

```bash
# 在 SITL 視窗執行
mode STABILIZE
```

然後手動控制降落。

## ⚙️ 自定義場景

編輯 `simulate_compass_interference.py` 第 20-30 行:

```python
SCENARIO = {
    'phase_1_duration': 10,   # 正常階段時長 (秒)
    'phase_2_duration': 20,   # 干擾漸增時長
    'phase_3_duration': 5,    # 嚴重干擾維持時長
    'phase_4_duration': 10,   # 恢復階段時長
    
    'normal_strength': 0.75,      # 正常強度
    'critical_strength': 2.0,     # 峰值強度
}
```

## 🔧 故障排除

### 問題: 連接失敗
```
❌ 連接失敗: [Errno 111] Connection refused
```

**解決**: 確認 SITL 已啟動並運行

### 問題: 模組未找到
```
ModuleNotFoundError: No module named 'pymavlink'
```

**解決**: 
```bash
pip3 install --user pymavlink
```

### 問題: 權限錯誤
```
PermissionError: [Errno 13] Permission denied
```

**解決**: 不要使用 `sudo`,使用 `--user` 標誌安裝
