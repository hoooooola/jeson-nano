# 動態磁力計干擾模擬 - 使用指南

## 📊 真實案例分析

以下是真實飛行中磁力計受干擾的案例,我們將基於此案例進行模擬訓練。

### 磁力計數據

![磁力計干擾案例](./案例_磁力計干擾.png)

**關鍵觀察**:
- **時間**: 15:11:15 - 15:11:28 (約 13 秒)
- **磁場總強度 (Total Sum Sq)**: 從 ~0.75 逐漸上升到 ~2.0
- **變化模式**: 先緩慢上升,後期急劇增加
- **各軸變化**: 
  - Mag X (紅線): 從 -0.5 上升到 0.75
  - Mag Y (綠線): 從 0.2 下降到 0
  - Mag Z (黃線): 從 0.75 上升到 1.0
  - Total (藍線): 從 0.75 上升到 2.2

### 姿態變化

![姿態變化](./案例_姿態變化.png)

**關鍵觀察**:
- **Pitch (俯仰角)**: 保持穩定在 0° 附近
- **Yaw (偏航角)**: 在磁力計異常時出現劇烈變化
- **Roll (橫滾角)**: 基本穩定
- **結果**: 飛行器進入姿態模式 (Attitude Mode)

## 🎯 模擬方案

我們提供**三種**模擬方法,從簡單到複雜:

### 方法 1: 手動 MAVProxy 指令 (最簡單)

**適合**: 快速測試,理解參數效果

**步驟**:
1. 啟動 SITL 並進入 MAVProxy
2. 起飛到 10 公尺
3. 手動輸入以下指令序列:

```bash
# Phase 1: 正常狀態 (模擬 0.75x 磁場強度)
param set SIM_MAG1_SCALING 0.75
param set SIM_MAG_MOT_X 0
param set SIM_MAG_MOT_Y 0
param set SIM_MAG_MOT_Z 0

# 等待 10 秒,觀察正常狀態

# Phase 2: 輕度干擾 (1.2x)
param set SIM_MAG_MOT_X 1000
param set SIM_MAG_MOT_Y 800
param set SIM_MAG_MOT_Z 1200

# 等待 5 秒

# Phase 3: 中度干擾 (1.5x)
param set SIM_MAG_MOT_X 2000
param set SIM_MAG_MOT_Y 1600
param set SIM_MAG_MOT_Z 2400

# 等待 5 秒

# Phase 4: 嚴重干擾 (2.0x) - 模擬案例峰值
param set SIM_MAG_MOT_X 4000
param set SIM_MAG_MOT_Y 3200
param set SIM_MAG_MOT_Z 4800
param set SIM_MAG1_SCALING 1.5

# ⚠️ 預期: Compass Unhealthy 警告
# ⚠️ 建議: 立即切換到 STABILIZE 模式

# Phase 5: 恢復正常
param set SIM_MAG_MOT_X 0
param set SIM_MAG_MOT_Y 0
param set SIM_MAG_MOT_Z 0
param set SIM_MAG1_SCALING 1.0
```

### 方法 3: Python 動態模擬 (全自動,最真實)

**適合**: 高級訓練,完全複製真實案例

**特點**:
- ✅ 自動平滑過渡 (模擬真實干擾漸變)
- ✅ 時間軸控制 (精確模擬案例時間序列)
- ✅ 無需手動輸入指令
- ✅ 可自定義場景參數

**執行位置**: ⚠️ **在 Host (主機) 執行,不是在 Docker 容器內**

**前置需求**:
```bash
# 在 Host 主機上安裝 pymavlink
pip3 install --user pymavlink

# 驗證安裝
python3 -c "import pymavlink; print('✅ pymavlink 已安裝')"
```

**使用步驟**:

#### 步驟 1: 啟動 SITL
```bash
cd simulation
./launch_all.sh
```

選擇 ArduCopter,等待所有組件啟動完成。

#### 步驟 2: 起飛並準備
在 SITL 視窗 (tmux window 1) 中:
```bash
mode GUIDED
arm throttle
takeoff 10
```

等待無人機穩定在 10 公尺高度。

#### 步驟 3: 執行模擬腳本
**在 Host 主機開啟新的終端** (不要在 tmux 或 Docker 容器中執行):

```bash
# 方法 A: 直接執行
cd /media/user/windowsData1/gitClone/GitProject/jesonEcosys/simulation
python3 simulate_compass_interference.py

# 方法 B: 使用您當前的終端 (ProcessId: 11677)
# 已經在正確的目錄,直接執行:
python3 simulate_compass_interference.py
```

> 💡 **為什麼在 Host 執行?**
> - Python 腳本連接到 `127.0.0.1:14550` (MAVLink 端口)
> - SITL 使用 `network_mode: host`,端口暴露在主機上
> - 在主機執行可直接訪問此端口

#### 步驟 4: 觀察與應對
- 切換到 Gazebo 視窗 (tmux `Ctrl+b 0`) 觀察無人機行為
- 切換到 QGC 視窗 (tmux `Ctrl+b 3`) 觀察警告訊息
- 當出現 "Compass Unhealthy" 時,立即切換到 STABILIZE 模式:
  ```bash
  mode STABILIZE
  ```

## 🔧 Python 腳本進階自定義

如果您想調整模擬場景,可以編輯 `simulate_compass_interference.py`:

```python
# 找到 SCENARIO 配置區塊 (約第 20 行)
SCENARIO = {
    'name': '馬達磁場逐漸增強',
    
    # 調整時間軸
    'phase_1_duration': 10,   # 正常階段時長 (秒)
    'phase_2_duration': 20,   # 干擾漸增時長
    'phase_3_duration': 5,    # 嚴重干擾維持時長
    'phase_4_duration': 10,   # 恢復階段時長
    
    # 調整磁場強度
    'normal_strength': 0.75,      # 正常強度 (相對地球磁場)
    'critical_strength': 2.0,     # 峰值強度
}
```

## 📋 MAVProxy vs MAV_CMD 說明

### 問題: 能否使用 MAV_CMD 函數?

**答案**: **不能直接使用 MAV_CMD 來設定 SIM 參數**

**原因**:
1. **MAV_CMD** 是用於飛行控制指令 (如 `MAV_CMD_NAV_TAKEOFF`, `MAV_CMD_DO_SET_MODE`)
2. **SIM 參數** 是 SITL 模擬器的配置參數,需要透過 `PARAM_SET` MAVLink 訊息設定
3. MAV_CMD 無法修改模擬器內部參數

### 可用的方法對照表

| 方法 | 工具 | 優點 | 缺點 |
|------|------|------|------|
| **MAVProxy 指令** | `param set` | 簡單直接 | 需手動輸入,無法自動化 |
| **MAVLink PARAM_SET** | Python + pymavlink | 可程式化,自動化 | 需要寫程式 |
| **MAV_CMD** | ❌ 不適用 | - | 無法設定 SIM 參數 |

### Python MAVLink 範例

```python
from pymavlink import mavutil

# 連接
mav = mavutil.mavlink_connection('udp:127.0.0.1:14550')
mav.wait_heartbeat()

# 設定參數 (等同於 MAVProxy 的 param set)
mav.mav.param_set_send(
    mav.target_system,
    mav.target_component,
    b'SIM_MAG_MOT_X',      # 參數名稱
    2000.0,                # 參數值
    mavutil.mavlink.MAV_PARAM_TYPE_REAL32
)
```

## ⚠️ 常見問題

### Q1: 為什麼我的參數設定沒有效果?
**A**: 確認您在 SITL 環境中,而非真實飛控。真實飛控沒有 `SIM_` 開頭的參數。

### Q2: Python 腳本連接失敗?
**A**: 檢查:
- SITL 是否正在運行
- 端口 14550 是否被占用
- 防火牆設定

### Q3: 如何查看當前磁場強度?
**A**: 在 MAVProxy 中:
```bash
status
# 或
watch COMPASS
```

### Q4: 模擬完成後如何重置?
**A**: 
```bash
param set SIM_MAG_MOT_X 0
param set SIM_MAG_MOT_Y 0
param set SIM_MAG_MOT_Z 0
param set SIM_MAG1_SCALING 1.0
param set SIM_MAG1_FAIL 0
```
